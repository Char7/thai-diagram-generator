# Per-image Quality Checklist

- [ ] Image/data provenance and rights confirmed
- [ ] Editable SVG text, shape and connectors kept independent
- [ ] Final PNG opened at full size and zoomed
- [ ] Thai vowels/tone marks readable (no strange stacking)
- [ ] No labels overlap connector, arrow or shape border
- [ ] Yes/No labels (ใช่/ไม่ใช่) beside connectors
- [ ] Original image aspect preserved at every scale
- [ ] No critical details cropped or stretched
- [ ] QA report has pass=true, collisions=[], aspect_failures=[]
- [ ] SVG independently verified in target viewer/editor
- [ ] Scientific/editorial content checked and approved
- [ ] Versioned files kept and owner acceptance recorded
